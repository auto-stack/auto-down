# @autodown/core

## 0.3.0

### Minor Changes

- plan 017: this package is now a re-export shim forwarding to `@autodown/engine` (same public surface, zero consumer changes). The parser/render/editor sources live in the engine package; retirement is planned with plan 020.

## 0.2.0

### Minor Changes

- Milestone: the editor's Vue component layer is now 100% generated from Auto language widget DSL sources (plans 010–013). `@autodown/core` (IAL utilities) is compiled from Auto as well. Public APIs, rendered DOM and the pixel baselines are unchanged — demo e2e screenshot suite and jade-garden e2e (23/23) stay green.

  - All 13 components (CodeLanguageIcon, four menus, seven node views, and the top-level `AutoDownEditor` assembly) are generated by the Auto compiler; the last hand-written shell/Inner split was eliminated in plan 013 (quoted msg variants carry the lowercase/hyphenated emit contract; `expose {}`, named slots and `withDefaults` runtime defaults are native).
  - Tiptap extensions, `useAutoDownEditor`, `StreamingRenderer`, `useSyncedScroll` and CSS remain hand-written by design, consumed by the generated components.
  - Compiler fixes landed upstream on auto-lang master along the way: quoted msg variant emits, Bina/receiver parenthesis restoration, `||`/`&&` computed operand-type inference.

### Patch Changes

- ef16ae2: Rewrite `@autodown/core` (IAL utilities) and `CodeLanguageIcon` in the Auto language, compiled to TS/Vue via the Auto compiler (a2ts / ui_gen). Public APIs and rendered output are unchanged; handwritten originals are kept as `.bak` references. See `packages/core/auto/README.md` and `packages/editor/src/auto/README.md` for the generation pipelines.
