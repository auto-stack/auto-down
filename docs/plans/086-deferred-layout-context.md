# [PLAN-086] 普通 Auto 延迟布局回调、测量与上下文查询

> 依据：[Design 10](../designs/10-autodown-publishing.md) §9–10、§14 的 P3 布局部分。硬前置为 [083](archived/083-document-style-render-rules.md)（已交）与 [084](084-publication-templates-semantics.md) 的交付。[085](085-live-pagination-preview-source-map.md) 供交互集成。状态为 drafting。

## 0. 变更摘要

在标准文档语义之上，验证普通 Auto 函数如何作为延迟内容使用，并开放明确范围的布局上下文、测量、计数器与查询。模板仍写 Auto，不另造给作者使用的脚本语言。

## 1. 目标与边界

- 明确排版前普通函数与排版中的纯回调两个阶段，保留一套语言语义/类型检查。
- contextual/layout 等库 API 接收回调；支持集内的表达式经可观察 IR 映射到 Typst。
- 使用实际布局信息生成内容，验证宽度相关排布、页码/总页数和至少一个自定义查询/目录场景。
- 未支持的函数调用/捕获/副作用给定位与能力错误；不能把固定页码节点说成任意 Auto 回调支持。
- 不默认标准 Typst 提供任意 Auto 宿主回调，不将修改 Typst 内核、自研排版或全部 Typst 包兼容混入本批。

## 2. 架构方案

普通 Auto 函数经现有语义/类型路径检查 → 支持能力分析 → LayoutExpr 数据 IR → Typst context/layout/query/counter/measure 结构。排版前的完整 Auto 模板继续正常求值。

LayoutExpr 是内部边界 IR，不要求用户书写它，不以另一个字符串 eval 解释器实现。若现有公共 AST/类型接口不足，最小反例交 AutoLang owner；本计划不在其他仓主检出临时改变编译器。

优先用 ACE 受检前端获得带类型与源范围的函数表示，通过实际可消费的公共接口检查布局能力并降为 `LayoutExpr`。T-00 用一条依据可用宽度生成内容的回调和一条超出能力的回调，核实类型、捕获、调用与源位置所需数据。模板运行端复用 084 的结论。布局表达式由 Typst 在分页时执行，CLI 即可做功能验收。

若公共受检接口缺项，交 AutoLang 最小回调样例和缺失字段，同时推进布局 IR、Typst 发射和内置上下文等独立工作。普通模板求值可沿用 084 验过的旧版路径。自定义回调的验收仍要求真实受检函数输入及其正反例。AGE 通过 085 消费最终页面和定位数据。

## 3. 详细设计

1. 先核定支持集：常量、可序列化只读捕获、上下文字段、长度/数值运算、比较、if、内容构造、标准计数器与引用。是否支持迭代/集合查询取决于实际 lowering，必须明确列出。
2. 回调按 occurrence 和实际插入环境延迟执行；同一个 Content 用两次，不得提前固化一个通用页码/宽度结果。
3. LayoutContext 提供受限的样式、尺寸、位置、测量与索引服务；外部数据在排版前读取，回调不依赖写文件、请求网络或外部可变计数器。
4. 编号/状态以出版树逻辑阅读顺序及位置读取；不能用回调执行次数实现文档编号。
5. query 语义对象与已知结构复用 084 的索引，位置由后端延迟取得。动态增加可查询语义节点首期可明确拒绝；装饰内容不默认污染目录。
6. 保留后端迭代与不收敛警告，宿主加请求/展开预算；不外套无界“直到成功”循环。结果携带 revision 与状态。
7. 不支持的布局回调使用稳定诊断类别，例如 E_LAYOUT_CALLBACK_UNSUPPORTED，包含源位置、原因与支持范围。

## 4. 测试与验收标准

| 编号 | 场景 | 成功条件 |
| --- | --- | --- |
| AC-01 | 普通 Auto 函数参与延迟布局 | 实际经语言检查和 lowering，输出不是硬编码的同一结果 |
| AC-02 | 同一内容置于不同宽度/位置 | 尺寸相关结果分别正确，测量使用真实上下文 |
| AC-03 | 页码、总页数与查询 | 自定义页脚/目录或统计示例正确，引用到已支持位置 |
| AC-04 | 重排与计数器 | 编号依最终逻辑顺序，多次求值不累加错误状态 |
| AC-05 | 不支持捕获/调用/副作用 | 给 Auto 源位置和能力错误，不静默执行或丢弃 |
| AC-06 | 不收敛/超预算 | 明确诊断与真实失败/警告状态，不把旧结果冒充新成功 |
| AC-07 | 与既有路线集成 | 082/084 样例可迁移；085 已就绪时验证同 revision 预览/导出 |

测量与查询应有两个以上上下文对照，不只检查生成字符串包含某个 Typst 函数名。正例与拒绝例共同定义实际支持范围。

## 5. 规范沉淀
