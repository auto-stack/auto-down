## Original content

双轨两栏布局机制：app.at view 树 row{h-full w-full} + 两 col{flex-1
min-w-0 overflow-hidden（左 col 带 border-r）}；VM 轨 row→
convert_row_tracked_ctx/col→convert_column_tracked_ctx（aura_view_builder
dispatch），flex-1→StyleClass::Flex1→width=Fill（iced_adapter :1024，
iced Row 两 Fill 子元素天然平分）；vue 轨 tag_to_tailwind（row=flex
flex-row/col=flex flex-col）+ class attr 直传，与 scoped style 并存。
工具类兜底形态：demo 构建无 Tailwind 运行时（package.json 无依赖/
engine style.css 无工具类/CustomScrollbar tailwind 串惰性三证），vue 轨
真 CSS 由 app.at style 块 scoped 工具类兜底定义（12 个 utility 精确
对应 view 树用量）+ :deep 增强（去 left/right 锚改直挂）。
组件臂 class 通路：autodown_editor class 解析进内层编辑壳（043 T6
包装 Scrollable 取合成 w-full h-full）；autodown 臂 class 整串不读
（渲染面板 py-4 px-5 缺席→观感族 W2）。left/right 未知 token VM 静默
跳过（parse_single 兜底）。

[PLAN-050 续收] 差异清册十二→十六项：#13 chrome 主题分叉/#14 标点不可见（翻案：视觉不可见非字符丢失）/#15 标签条塌陷/#16 行内叠字——四行收口，W2 主题族 fence 段续收。
