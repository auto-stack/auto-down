## Original content

主题机制：app.at model 声明 renderer 识别名 dark_mode 变量（var dark_mode bool = false），auto-lang Plan 370 D-GAP sync（renderer.rs read_state("dark_mode") 臂）每 view 更新推 iced_adapter::set_dark_mode——声明初值即首帧主题，a 案零 auto-lang 改动；Plan 458 env 种子（AUTO_UI_THEME）仅设置时介入。种子机制：content.ts 单源→scripts/gen-vm-content.mjs 转义单行字面量生成 app_ext.vm.at（GENERATED 头注+再生命令，幂等）→顶层 use.web.fn initial_content 经 app_ext.at 码评锚走 442 A3 适配器链（X.at→X.vm.at→X.web.at）。关键门控事实：.ts 导入路径从不进适配器链（ext_stubs.rs load_at_ext_imports 直 skip）；auto-man ext 拷贝 widget-use only——锚文件与顶层 use.web.fn 对 vue 构建双不可见（gen ext 目录仅 app_ext.ts 原样拷贝，复验）。

【PLAN-051 supersede 注记 2026-09-04】主题机制延伸至运行时切换器（settings 双轨+引擎 props 声明入口+fence buffer 重着色），由 P051-3 接替扩展；本条 D-GAP/浅色盘内容仍有效。
