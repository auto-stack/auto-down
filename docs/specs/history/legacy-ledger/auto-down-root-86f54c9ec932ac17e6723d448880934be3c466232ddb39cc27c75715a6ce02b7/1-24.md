## Original content

四层纪律（真值流，规约先行——杜绝 vue 专属 CSS 注入承载语义）：

1. **语义层（DSL 状态）**：`dark_mode`（app.at:147 既有）/`accent_color`（新增）——VM 经 Plan 370 D-GAP 消费，vue 经绑定消费。
2. **声明层（视图树）**：app 级 chrome 条件类串（`.app-dark`）+ 引擎标签 `dark_mode:`/`accent:` 绑定（vue.rs 两臂发射 `:dark-mode`/`:accent`；VM 臂 prop 惰性、经全局链路自达）。
3. **规约层（Design 22 §7）**：每受主题影响的面的取值先落规约行（格式照 §4.6：规约值+Vue 锚点+VM 锚点）；深色档以 VM zinc 现值为基准反向对齐（与 050 浅色档互为镜像）。
4. **实现层（双端投影）**：引擎 CSS `.is-dark` 修饰类+`[data-accent]` 覆盖组（取值逐条对齐规约行）；VM `family_of` 常量双档+`hljs_scope_map.rs` 镜像。

**关键结构裁定与锚点**：
- demo 与 stream-demo 保持分立：demo=VM 平价锚（默认布局不动），stream-demo=测试仪器（对拍逻辑不可跨模式泛化）；三模式统一开关另行立项。
- 引擎主题 token 层：`--ad-*` 中性板双根声明 + 五 accent `[data-accent]` 组 + `.is-dark` 档（strong→400 步、soft→accent@15% 经 `--ad-accent-rgb`）。
- `native_button` 显式原生逃生名：避开 `button`→shadcn `<Button>` 映射（reka-ui 依赖链），VM 两臂 button 同臂别名；`shadcn: off` 整关方案否决（连引擎组件映射一起关）。
- `app_ext.at` 空锚点+`use.web.fn` 转发声明 = Plan 424 认可的纯转发口形态（X.vm.at 链优先序不受影响）。
- DEBTS 050 处置：`retheme_all_fence_buffers`（core.rs）挂 renderer 两翻转臂（Plan 370 D-GAP 值变化臂+Plan 518 set_theme 执行臂），fence 叶 `ViEditor::update_theme` 换档；PLAN-050 `ensure_code_family_spans` 帧内幂等自动补回 family span。
- 子→父 emit 三补面（dynamic.rs/aura_view_builder.rs）：纯 emit 子件 HandlerNotFound 后声明式路由照派；Plan-367 引号键 `on"SetTheme"` 剥引号归一；`dispatch_parent_route` 按 `handler_param_count` 裁剪零参幻影载荷（与 PLAN-059 T9 musk 趋同汇流，注释双实证）。
