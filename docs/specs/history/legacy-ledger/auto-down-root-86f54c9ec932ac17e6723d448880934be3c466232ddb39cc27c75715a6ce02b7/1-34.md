## Original content

网页轨四段机制：通道模块 click-caret.ts（单槽 pending store，键=将挂载编辑面的块 id，
载荷三类）；捕获 slotChrome.onClick 先 resolveClickHit 解析归属再 captureClickCaret
（只对可消费命中记录，if(hit.anchor)）；解析 = 叶块自身/表格 caretRangeFromPoint+行列
定位/折叠容器叶包装↔模型原子子叶按文档序配对（数不等回退深选不猜）；消费 = 编辑面
挂载后以同一 caret API 重解点（两面布局等价落同一字形）。VM 轨：handle_mouse_press
单趟 hit_test+Action::Click+locate_leaf（cell 一等叶 buffer），无预览面替换环节。
