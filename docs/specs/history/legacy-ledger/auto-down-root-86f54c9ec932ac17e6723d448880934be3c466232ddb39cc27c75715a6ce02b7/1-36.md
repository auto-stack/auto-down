## Original content

- **命令/显示状态分离**：scroll_top 写臂唯一绑 *_top_cmd（用户拖拽/同步
  跳转写入），onscroll echo 只写 *_top_view（thumb 显示+测量）——echo→写臂
  回环边结构性删除，任意引擎行为下振荡不可能发生。
- **单向块锚定管线**：编辑壳 scroll 回调锚块判定（首个完整可见块，tol 2px）
  → 锚槽注册（pending）→ 渲染 update 尾 drain → content_y（前块高累计+
  列间距，AnchorSlot 布局期记录块高，屏内外均有效）→ write_state 直写
  right_top_cmd（写臂既有通路滚动；sync_anchor_block 直写供断言观测）。
- **iced 0.14 委托 wrapper 树规范**：委托 widget 的 update/mouse_interaction
  必须传 tree.children[0]（container 等透明委托件 update 原树透传——传自身
  树会把无状态树错配给孙代，downcast 崩）；operate/overlay/size_hint 同步
  委托。检视层（VNode/snapshot）对包装件透传子件。
- **注册表单文档约定**（v1 限度）：AnchorSlot 块高注册表全局单文档。
