## Original content

- **三分类注册表**（desktop/ext-registry.json）：sink=下沉 .at（含
  web-codegen shim——图标/组件/facade 再导出，widget .at 化即原生取代）；
  bridge=VM 原生·宿主桥（clipboard=arboard、localStorage=401 session
  KV、#[api] 通道）；deviation=登记偏差（confirm/matchMedia/dir-picker/
  ensureBlockAnchors）。禁止第四类 "jade 侧绕过"——平台能力缺口走
  auto-lang 提案（P022 §7.1 裁定延续）。
- **双表对拍门检**（desktop/scripts/ext-registry-gate.mjs）：导出面 ↔
  注册表逐 (file, fn) 精确匹配（未登记=红/死账=红）；store `use back.api:`
  名单 ⊆ 对应 <stem>_ext.ts 导出面（sed 契约）；.at 源 `use {…from}` 引用
  必须已登记。接入点=独立 node 脚本，不改 gen.mjs（避免发射器面扩大）。
- **vm-smoke harness 模式**（desktop/vm-smoke.mjs）：AUTOUI_MCP_PORT +
  `auto run -r vm`（split：AUTO_VM_MERGE=0 + AUTO_BACKEND；AUTO_BACKEND
  驱动 340 HTTP 改写，模式横幅措辞与实际通路无关）；断言全走 MCP 合成
  通道（autoui_state/snapshot/action——物理点击通道不稳，P022 slice 3
  登记项②）；fixture git 语义恢复协议（hash 契约=wiki/**/*.ad 文档面，
  后端索引 sqlite/edn 非契约；scoped checkout+clean）；MCP initialize ≠
  UI 已渲染（臂前须轮询首帧快照）；仅杀自 spawn PID（PLAN-049 卫生）；
  窗口偶发自退重试一次。
