## Original content

- **注册表**（auto-lang src/ui/native_widget.rs）：View/Element 双入口——View factory 派发期产 View（案 a sugar：组件用既有 View 词汇表达，autodown_editor 首迁即此形态）；Element 入口派发产 View::Custom { name, props, events, style }，iced lowering 期查表（首个后端原生件落地时建 Element factory 表，现防御臂=零高 Space）。同名注册拒绝记 violation；折叠查找（P435 P8-6 同规）；dump() 门检面。
- **派发序**（aura_view_builder 两站点 fallback）：内置硬编码臂 → NativeWidgetRegistry（builder 字段缺省=进程级 global，feature 门控注册；测试经 with_native_registry 注入）→ .at AuraWidget → 折叠兜底 → 未知 tag 兜底。未注册名行为与迁移前一致（保形）。
- **View::Custom**：name+props 明文透传（快照 kind=注册名、props 在场——MCP 断言面保明，不用 Box<dyn>）；事件→消息派发期解析、按键排序保快照确定性；iced/gpui/vnode 三面配套臂。
- **治理**：schema 漂移围栏（P435 P0）扩面——scan_native_registrations 把注册名并入 vb 并集（mod tests 截断免夹具混入），外部组件天然受围栏覆盖，臂式/注册表式注册同权。
- **首迁 autodown_editor**：双拼写直接键注册（autodown_editor+autodowneditor）+无 feature textarea 降级注册（D-GAP-3 链保持），臂体提取 convert_autodown_editor_native（pub(crate)）。
- **stream 渐进（编辑臂）**：core 流式位 readonly=streaming（TS stream→edit v1 裁定）+ handle_input 全门控 + 尾部状态条（高度计入 DocFrame.height）+ rebuild_with parse flag 直通单源三态（P032）；「恒按 final」豁免摘除。
