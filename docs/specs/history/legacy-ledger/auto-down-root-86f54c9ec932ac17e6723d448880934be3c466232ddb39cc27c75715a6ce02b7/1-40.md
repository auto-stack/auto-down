- **tab 条契约（README §9.6，SD-01）**：041 双分支结构（Plan 449：view fn 片段参数化条件不求值，激活/非激活须双分支，t.path 与 .active_path 比较）；激活 tab=高亮行 bg-[#1C1D24]（括号 style: 形式——class: 括号式遇任意值整串丢弃，实机快照实证；外层条/分隔线 class 花括号式不受影响）+ amber * 脏标（t.dirty 门控）+ x 钮（icon name:"x"）；x 钮=零参 .CloseTab（活动 tab 语义，Tabs.Close(.active_path)），只出现在激活行，不新增带参 msg（tabs_store 零改动红线）；无 + 新建钮（六流无新建流，登记偏差另行计划）。smoke 锚：tab 标题钮 ownText=t.title 不变；x 钮=唯一空文本 button（icon 快照渲染 [Image] 文本节点，name prop 不可见）。
- **正文编辑器换装 autodown_editor（SD-02）**：autodown_editor (key: .active_path, final: true) { content: .active_body, oninput: .Edit }——播种口径标签无关（content:=初值+每帧外部 diff 回写，键变重挂载）；.Edit(str) 单参通道不变（INPUT_TEXT 注入与 code_editor 同约定，demo 同 exe 实证）；零内建调用（041④ 坏字节码红线，读路径由 .Edit 全文载荷覆盖）；final:true=文档恒终态。消费 PLAN-066 NativeWidgetRegistry（auto-lang master 72fd9d70c）。
- **isEditorNode 四形态（Q1 冻结）**：textarea/code_editor/autodown_editor/AutodownEditor；本机 exe 投影=textarea+value 全文（与 autodown/demo/auto 编辑面同 exe 同形），后两拼写为真块编辑壳 exe 预留。
- 持久契约全文：jade-garden/front/desktop/README.md §9（§9.6 新增+§9.2/§9.4 更新，PLAN-068 增量）。
