## Original content

- **六助手处置终态**（use back.api 契约 fn 名化：read_wiki, write_wiki,
  ensureBlockAnchors, recordRecent, confirmClose, rethrow）：
  rethrow=deviation（web ext 再抛保 facade rejection 传播/VM plain fn
  吞错——DSL 无 throw 且 catch 强制必填，编译器实证）；
  stripExt/adoptSaveResult=sunk（store 文件 module fn，Plan 367 P2-4，
  纯值 CAS 双树可用）；readWikiSafe=内联 try/catch null 映射（3 调用点）；
  ensureBlockAnchors=deviation（web 全量 parser_gen/VM identity——与骨架
  save 现行为一致）；recordRecent=bridge（web Pinia/VM 401 session KV）；
  confirmClose=deviation（web window.confirm/VM 默认确认即弃）。
  ext 收缩为 web shim 面（6 导出）；api.at 增 VM 助手层 4 plain fn（无
  #[api]，契约门不计）随 gen.mjs 部署 desktop 副本。
- **tabs 流 v1 形态裁定**：widget 状态机等价实现（022 Phase 3 双读竞争
  防护语义保形：已 loaded 重复 Open 只激活不重读、CAS 回声采纳；closed
  标记删除——VM 模型数组 splice 静默失效绕行；反链 source_path 为页标题
  需 .ad 后缀归一）。tabs_store facade 迁移前置 = auto-lang 提案⑥
  （store facade VM 缺口簇：handler 读 store 字段失效/视图不响应式回读/
  store 内 #[api] 不走 340 改写/splice 失效/lambda 本地捕获编译错），
  修复后 desktop 回归 `use store: Tabs` 形态（desktop/README §8）。
