vue 轨 view 正确性收口 + view≡stream 自动门 + 主题规约化（深浅/accent）+ 双轨 settings 全落地（T1-T11 + 复审修正，双仓十提交）：

- **规约先行**：auto-lang Design 22 新增 §7「AutoDown Document Face 规约」章——浅色档逐值盘点（引擎 CSS 双载体 34/33 去重值+家族 widget 散值+mermaid 参数全收，`comm` 程序化零游离核对）+ 深色档（VM zinc 基准，VM 零改动）+ accent 五色三件套 + hljs 双档（hljs_scope_map 生成物单源）+ 排版分叉登记 + 编辑壳交互面归置。
- **引擎**：accent 双定义收敛单源（`.autodown-editor,.streaming-document` 双根规则）+ `darkMode`/`accent` props 声明入口（根 `.is-dark`+`data-accent`，缺省档零差异）+ token 层/深色覆盖块/hljs github-dark 组双侧落地。
- **双轨 settings**：`settings_popover.at` 适配件（shadcn token→具体值类、组件自带 scoped 兜底）+ `native_button` 原生逃生名（配 auto-lang VM 别名，零 shadcn/reka-ui 依赖）+ `app_ext.at` Plan 424 纯转发声明（解锁新 auto-man 校验中断的 vue 工程发射——vue-tsc 门曾被静默跳过的根因）；stream-demo 手写 settings + view≡stream 对拍自动门。
- **VM**：fence buffer 运行时重着色（`retheme_all_fence_buffers` 挂两翻转臂，DEBTS 050 销号）；子→父 emit 三补面（纯 emit 子件派发/Plan-367 引号键归一/幻影载荷裁剪，与 auto-lang PLAN-059 T9 趋同汇流）。
- **复审修正**：a2vue golden 随 T5 契约更新；swatch 作用域特异度修正；stream-demo 深色页 chrome。
- **门读数**：引擎 vitest 786/786；demo playwright 74/74；stream-demo 对拍 3/3 首跑零差异；vm-smoke 11/11；tf 失败集≡master 两红基线；tv 3571/3571。证据八件（vue-051×3/stream-051/vm-051×2/探针×2）。
